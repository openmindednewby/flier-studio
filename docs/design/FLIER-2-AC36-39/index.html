FLIER-2 "Flier Studio follow-ups": draft names, delete and clean-up, Same width, Same size (AC-36..39)

Live build live index-D2oPVMyr.js with each option applied by restyling the real rows and redrawing the real flier (drafts.ts, lines.ts). Galaxy S5 360x640 and Desktop Chrome 1280x800, light and dark; six drafts made by typing five titles at fixed times, two starred; the same steps for before and after (capture.spec.ts, frames/*.json, result.json). The line tools and the redraw are a target, not built: Same width and Same size need a per-line size in @dloizides/poster-render (D25).

Today: KIZOMBA 627 px wide at 169 px, WORKSHOP 701 px at 149 px (flier 1, canvas 1080 px). Same width scales the second line until both draw at one width (±1 px), inside the margins. Same size gives the second line the first line's size, shrunk only if it would cross the margins. Both apply to the flier you are editing, and a theme change keeps them.

AC-40 Per-field text style (D26): every text field (Title, Second title, Script line, Includes heading, Footer, Venue, Schedule, Prices, Includes items, Items) gets a Style control: font, size, colour (palette swatches + Custom), Bold / Italic, letter spacing and alignment, applied to this flier or all 4, with Reset to theme. A theme switch keeps it, and the text itself never changes. Size is shared with the line tool: Same width and Same size set the same per-line size. Panel open in the frames: Second title. Target, not build.

All three: a draft is named after its first flier's title and the time ("KIZOMBA, 11:12 AM"); a renamed draft keeps its new name. Delete one draft: it goes at once, and "Deleted ..." with Undo stays for 5 s, above the phone's flier bar. Clean-up deletes every draft that is not a favourite, after a confirm that says how many go and that favourites stay. Favourites are never deleted in bulk.

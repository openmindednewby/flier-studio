## Ruling on the logged R8 gap (Generate + Download all both filled)

R8 (approved, page 2 Q1) is "one filled primary per view". At 1280 both filled buttons are on screen in the top frame, so the gap is real, not a 360-only artefact. **Download all PNGs keeps the fill**: it is the product's outcome (the purpose line ends "download the PNGs"), it is already the focused default in the previews state, and R3 puts the one accent/fill on the main action. **Generate becomes the outlined 1 px secondary**, like Import file / Make share link; it is one input path among several (preset, import, share link, the form). No item is removed or hidden. Scored as #4 = 3, not a hard fail; it must ship in the next style change to `src/ui/promptPanel.ts:34` (drop the `'primary'` variant). In the mini sheet / import / cutout dialogs the one primary per dialog stays as is (each dialog is its own view).

## Top fixes (at most 3)

1. **Generate outlined, not filled** (R8 ruling above): `button.primary` off Generate in both themes; Download all PNGs stays the only fill. Before/after pair at 1280 light + dark top.
2. **Flier canvases radius 8 to 0** (R6 "fliers = square paper"): the crop marks at the selected flier's corners then meet a square sheet instead of floating 4 px off a rounded corner (visible at 1280 flier 1, all four corners).
3. **Crop marks readable at 360**: today about 6 px long, 1 px, so flier 1 and flier 2 look the same at 360 light. Make each arm 12 px, 2 px, in `--primary` light / brandFill dark, offset 4 px from the sheet.
